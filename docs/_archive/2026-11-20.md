## 修复企鹅近战"冲进敌人中心"bug（BabyPenguinGlobalProjectile.cs）

- 现象：贴边砍一段时间后"莫名其妙再索敌"，企鹅直接冲进敌人中心挥砍。
- 根因：① `FindNearestTarget` 每帧重选最近敌人，目标在相邻敌人间跳变；② Approach 朝 `target.Center` 加速 + `Hitbox.Intersects` 离散帧检测，冲过头那帧仍判相交，把中心记成 meleeHoldPosition。
- 用户确认方案：目标锁定到失效（标记目标可强制切换）+ 几何精确贴边接触点。
- 实现：
  - 新增字段 `lockedTarget`（whoAmI）；`FindNearestTarget` 改为实例方法 `ResolveTarget`：标记目标最高优先可强制切，否则沿用锁定目标（存活/可追/在 DetectRange 内）才重选；ResetState 里清 -1。
  - 新增 `GetContactPoint`：从敌人中心朝企鹅射线，slab 法算与敌人框+企鹅框边界交点距离之和 + ContactGap(4px)，得贴边接触点；`PinToContact` 用 `projectile.Center = contact` + 清速度钉住。
  - Approach 的 Melee 分支改为追 contact、到位距离 <= ContactArriveDist(10px) 或 hitbox 相交即 PinToContact + 挥砍；Ranged 分支仍追中心不变。
  - `UpdateMode` 的 Ranged→Melee 判定从 hitbox 相交改为到接触点距离 <= ContactArriveDist+ContactGap（因贴边后不相交，原判定会失效）。
  - 文件头注释同步更新。
- 验证：C# 编译通过（bin/Debug/net8.0/TutorialMod.dll 新生成，0 警告）；打包 .tmod 因 tModLoader 游戏运行中占用 Mods/TutorialMod.tmod 而报 TML003，属环境占用非代码问题，需关闭游戏后再 build 完成打包。
