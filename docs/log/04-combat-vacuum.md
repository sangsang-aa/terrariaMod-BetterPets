# Bug 4 · 5 秒切换的战斗真空期边界推演

> 重构时主动做的边界分析，非实测 bug。已加追击超时阀解决。

- **问题**：切近战时若离目标太远，5 秒内追不上就会空转。
- **推演**（速度 15f / 帧，5 秒理论能跑 4500px，索敌半径 600px）：
  - 静止 / 普通敌人：0.2~0.5 秒贴边，无真空。
  - 快速敌人：约 0.6 秒贴边，无真空。
  - 冲刺型 BOSS（≥15f/帧）：同速或更快，永远追不上 → 整段 5 秒近战空转。
- **修正**：加「追击超时阀」`MeleeChaseTimeout = 90` 帧——切入近战 90 帧仍未贴边就提前切回远程，把最坏真空从 5 秒压到 1.5 秒；正常战斗触发不到。
- **教训**：固定时长的模式切换要考虑「目标速度 ≥ 己方速度」的极端边界；用一个更短的超时门兜底，比拉长模式时长更稳。方法见 [method/05](../method/05-chase-timeout.md)。
